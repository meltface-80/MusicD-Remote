Rouen

A music-discovery companion and full-screen wall display for Roon — random-album browsing, instant whole-library search, rich label & artist pages, and seamless playback with Roon Server at the heart. A Rouen is a duck — MusicD is short for Music Duck. Called MusicD Remote until v1.8.74; install commands, the image and the data volume keep their musicd-remote names.

v1.8.73 Docker MIT licence Pairs with your Roon Core over the network

Features

Everything talks to your existing Roon Core through the official extension API — the app never changes your library files. An optional read-only /music mount adds file-tag labels, release dates, local waveforms, the local-files badge and the format filters. Tap i on any feature for how to set it up and use it.

🐳A ready-made imageNew

Install with one docker run — nothing to download or build — from ghcr.io/meltface-80/musicd-remote, built for x86 and 64-bit ARM: PCs and NAS boxes, a Raspberry Pi 4 or 5 on a 64-bit OS, Apple Silicon Macs. Updates stay one tap in the app, and switching an existing install needs no reinstall: remove the old container and run the image with the same volume, and your Roon pairing and history carry over.

How to set it up and use it. Build your command with the configurator below and run it. In Roon, go to Settings → Extensions and click Enable on Rouen, then open http://<server-ip>:3399 on any device. The image and the data volume keep their musicd-remote names, so an existing install carries on unchanged.

🔄Your library, followed in secondsNew

Add albums in Roon and they are in the app within about a minute, with no rescan. While the app or the wall display is open it checks Roon every 30 seconds (every 3 minutes when nobody is looking) with three tiny calls that cost the Core almost nothing, follows a change until Roon settles, then reads the library once — so a big import costs one pass, not one per album. The side menu says when the library was last checked.

How to set it up and use it. Nothing to switch on. To force a fresh read, open the side menu (☰) and tap the Rescan library line at the bottom — it also shows the album count and when Roon was last checked.

⚙️Settings, redesignedNew

A compact list — an icon and a title per row, in place of the grid of large buttons. Every page opens full screen, however much is on it, with its title and back arrow pinned at the top while a long page scrolls. Listen later sits right under Home in the side menu.

How to set it up and use it. Open the side menu (☰, top left) and choose Settings at the bottom. Tap a row to open its page; the back arrow returns to the list and × closes Settings. A setting with an ⓘ explains itself when you tap it.

🕒Listen later

Put an album aside to play another time — from its ⋯ menu, from a selection of albums on any wall, or with ＋ Listen later on a Smart Pick. Roon's own Listen later can't be reached from an extension, so this is the app's own list: kept on the server, the same on every device, and safe across a library rescan. Albums you own play straight from it; a Smart Pick that isn't in your library yet can be added in one tap or opened in Qobuz or TIDAL. It tidies itself: an album comes off once every track has been played through since you put it aside, on any zone, from any app.

How to set it up and use it. Choose Listen later from an album's ⋯ menu, or long-press albums on a wall to select several. Find the list under ☰ → Listen later or on its Home row (switch the row on or off and move it under Settings → Home Screen). To send each day's Smart Picks here, set Settings → Smart Picks → Send each day's picks to → Listen later.

↔️Previous & next album

Swipe the album card sideways, tap the chevrons on the cover's edges, or use the arrow keys to step to the albums either side — on the screen you opened it from, whether that's a Home row, the Library wall, or an artist or label page. Close the card and you land on the album you stepped to.

How to set it up and use it. Nothing to set up. Open an album from any row or wall, then swipe, tap ‹ › on the cover's edges, or press ← / →. An album opened from search or Now playing has no neighbours.

📺Remote ⇄ wall display

☰ → Wall display turns the remote into the wall display for its zone, and the brass ‹ Remote button on the display brings it back exactly as you left it. A screensaver timer switches to the display after 1 to 60 minutes untouched — per device and off unless you choose it. It waits while Settings, a sheet or a selection is open.

How to set it up and use it. First switch on Settings → Wall display → Wall display; the menu entry and the screensaver only appear while it is on. For the screensaver, on the device you want it on, pick a time under Settings → Wall display → This device → Switch to the wall display. On the display, tap anywhere to reveal the mode buttons and ‹ Remote.

📡Live screens

Every screen keeps itself up to date. Home, the Library and Not played walls, the Queue, the album, artist and label pages, Smart Picks and Discover refresh themselves when something changes — a play, a release date found, a setting changed on another device. In place: your scroll position stays, nothing flashes “Loading…”, and nothing moves while your finger is on it.

How to set it up and use it. Nothing to switch on. Every open device checks the server every few seconds while it is on screen — so an album played on one phone leaves Album of the day on every other device too.

🧭Discover

New records by the artists you actually listen to. Read from your play history rather than your library, and ranked by how many separate days you played an act rather than by play count. Albums only, from the last two months, never a record you already have — and a remaster is refused only when the title says so and the act has an older release under the same name. Every row goes somewhere: in your Roon library it queues, otherwise it opens in your default streaming service. Uses Deezer's public catalogue and never touches your Roon Core.

How to set it up and use it. Switch on Settings → Discover → Discover (off by default) and pick the hour under Look for new records at (server time). It looks once a day; Refresh on the same page looks now. Then open ☰ → Discover. It works from your play history, so it gets better the more you listen. Your default streaming service is set under Settings → Share Card → Default.

📤Share card

Tap Share on any album or on Now playing and the record gets a card of its own — artwork, artist, title, release date and label, a description, and the Pitchfork score with its Best New Music flag where there is one. Underneath: where to hear it (Qobuz, TIDAL, Spotify, Apple Music, Amazon Music, Deezer, Bandcamp — and Qobuz opens the Qobuz app) and where to read about it (Wikipedia, Pitchfork and AllMusic for the album; Wikipedia and AllMusic for the artist if you want them). And “If you like this” suggests three acts worth hearing next — one in your Roon library is queued, one that isn't opens in your default service.

How to set it up and use it. Tap the share button in an album or on Now playing. Choose which services and review links appear, and the default service, under Settings → Share Card; holding a service button under the card also sets the default for that device.

〰️Waveform

The seek bar on Now playing and the wall display's progress strip draw the shape of the track you're listening to — where the quiet intro ends, where the loud middle is. Every bar is the level of its slice of the track, measured from both channels at full rate, and the shape sits under the playhead at every point in the track. Each track is analysed once and stored, and the next one in the queue is prepared while the current one plays. Works for local files and for Qobuz and TIDAL streams — Roon sends those straight to your endpoint and never to an extension, so the track is fetched from the service with your own account, turned into 4,000 loudness values and discarded. The audio you are listening to is never touched, no audio is written to disk, and Roon still handles all playback. Anything the app can't identify keeps the plain bar.

How to set it up and use it. Switch on Settings → Playback → Waveform (off by default). Local files need your music mounted at /music; Qobuz and TIDAL tracks need that service connected under Settings → Streaming accounts. Play something and open Now playing — the first play of a track takes a second or two to analyse.

🎵Album discovery

A screen of random albums with filtering; Album of the day — the same album on every device from 00:01 until it is played anywhere, then a new one at the next 00:01; Random Album, one tap for an album you haven't heard in 12 months (its disc turns slowly and spins up while it chooses); Not played in 6 months, which starts once there are six months of your listening to go on; and Label of the week. The database learns what you've heard and resurfaces forgotten albums.

How to set it up and use it. All on Home. The first row leads with the Random Album disc — tap to play — then Album of the day (★ Today). Choose rows and their order under Settings → Home Screen. ☰ → Random albums opens the full random wall; the shuffle button draws again and Filter narrows it by genre, tag or decade. Set TZ in the install command so 00:01 is your 00:01.

📚Rich library browsing

Browse by album, artist, genre, record label, decade or tag — or open the Library row on Home and scroll your entire collection, with Sort, Focus and a grid/list switch. Dynamic Playlists, your Roon playlists and playlist import live in the side menu. Tap an artist in an album to see all their albums, and the brass ‹ beside the menu takes you back to that album. Artwork is cached on the server, so even a large library scrolls smoothly without waiting on your Core.

How to set it up and use it. Tap the Library title on Home, then use Sort (album, artist, release date, plays, last played, random) and Focus (decade, genre, source, listening) at the top. Dynamic Playlists, Playlists and Import a playlist are in the side menu (☰).

🔍Powerful search

Instant whole-library search by album, artist or record label. When Qobuz or TIDAL is connected their catalogue results are added, along with Pitchfork reviews — browse the streaming catalogues and add favourites straight into your Roon library.

How to set it up and use it. Tap the magnifier at the top of Home and type. Connect Qobuz or TIDAL under Settings → Streaming accounts to include them; they then also appear in the side menu for browsing.

💿Detailed album pages

Edge-to-edge artwork, track listing with per-track Play now and Queue, release date, label, every credited artist as a link, a description of the record, and the Pitchfork score with a link to the review where there is one.

How to set it up and use it. Tap any album. Play now and Queue sit under the title, and ⋯ holds Next, Shuffle, Radio and Listen later. Tap a track for Play now / Queue, or long-press to select several.

📺Full-screen wall display

Turn a TV or tablet into a now-playing display: big artwork, artist photography, biographies, reviews and “More from” grids from your library you can tap to play, with automatic rotation or one mode pinned.

How to set it up and use it. Switch on Settings → Wall display → Wall display (off by default) and set Rotate every. Point any browser at http://<server-ip>:3399/display, or choose ☰ → Wall display. Artist photos need a FanArt.tv key. Tap the screen for the mode buttons (Auto, Art, Photos, Bio, Review, Library) and ‹ Remote.

🏷Record label explorer

Label of the week, label logos via Discogs and FanArt.tv, label merging with undo, every release from a selected label, and labels taken from your folder names if your library is filed that way.

How to set it up and use it. Switch on Settings → Labels → Record labels — it is off by default, and nothing label-related runs until it is. Add the optional API keys for logos. Then open ☰ → Labels: long-press tiles and tap Merge to combine labels, tap “N merged” on a tile to undo.

📻Random Album Radio

When the queue finishes, the app picks another whole album (avoiding recent plays) and keeps the music flowing indefinitely.

How to set it up and use it. Switch on Settings → Playback → Random album radio for the zone chosen there. Roon Radio is the alternative on the same page; turning one on turns the other off for that zone.

▶Playback integration

Play or queue albums and tracks, multi-select, seek, shuffle, repeat and volume, move the queue between zones, group zones and power devices.

How to set it up and use it. Pick your zone under Settings → Playback → Zone / output (per device), or with the speaker button on the mini player. Tap the mini player for Now playing; its device button holds the zone tools. Long-press albums on any wall to select several.

🎨Two themes, one look

Graphite and Brass (the default) and Brass light, both meeting the AA contrast standard: a greeting and today's date at the top of Home, section titles in small brass capitals, rounder covers, a mini player with a level meter and toasts that sit above it, and a ✓ in every API key box once the key has been accepted.

How to set it up and use it. Choose a theme under Settings → Appearance → Theme and tap Apply — remembered per device. Show sample rate on artwork on the same page adds bit depth and sample rate to every tile.

🔄Automatic updates

Checks GitHub for a new release at startup and every 7 days, with one-tap updates installed in place — on every install, the ready-made Docker image included.

How to set it up and use it. When a release is out, a banner offers Update; tap it and the app reloads on the new version. Settings → System → Check for updates looks straight away.

Install with Docker

Pick where you're running the app, fill in the details, and copy the generated command. On Linux the app uses host networking so it can auto-discover your Roon Core; once it's running you enable it in Roon → Settings → Extensions.

The address of the machine running Roon Server — find it in Roon → Settings → General.
The port you'll open in your browser.
A container runs on UTC unless told otherwise, which moves Album of the day (it turns over on the wrong midnight, and so does the “already played today” check that hides it) and the hour Smart Picks switches. The not played in 6 months and 12 months windows count elapsed time, not calendar days, so they read the same in any zone. Pre-filled from this browser.
Both are optional and both improve label logos and artwork — see API keys below for where to get them. You can skip them here and paste them into Settings after first launch instead; a key saved there always wins over one set at install.
# Run it — --pull always fetches the current release every time this runs
docker run -d \
  --name musicd-remote \
  --pull always \
  --restart unless-stopped \
  --network host \
  -e TZ=Etc/UTC \
  -v musicd-remote-data:/app/data \
  -v "/your/path/to/Music:/music:ro" \
  ghcr.io/meltface-80/musicd-remote:latest

Installing v1.8.73 (checking for the latest release…). If your user isn't in the docker group, prefix the docker commands with sudo. Needs Docker 20.10 or later, the first whose docker run takes --pull.

One volume to rule them all. The musicd-remote-data volume holds your Roon pairing, play history and label cache — never rename it once created. A different name silently starts empty (Roon asks you to authorize again and your history is gone). Upgrading from v1.6.31 or earlier? Move your data once with the copy step in the Updating guide.
Already running Rouen (or MusicD Remote, its old name)? Nothing to uninstall and nothing to re-pair: docker stop musicd-remote && docker rm musicd-remote, then run the command above with the same volume. Your Roon pairing, history and settings carry over. From then on, updates are one tap in the app.

API keys

All free, all optional — but they significantly improve artwork and label coverage. Paste each one into the app under ☰ → Settings → Artwork & metadata, then Save — the box shows a ✓ once the service has accepted the key. Label logos also need Settings → Labels → Record labels switched on.

Free

FanArt.tv

Record-label logos for labels that have a MusicBrainz MBID, and the wall display's artist photos.

  1. Register (or sign in) at fanart.tv/get-an-api-key and request a personal API key
  2. Follow the on-screen prompts — the key is shown on that page once you're logged in
  3. Copy the key
  4. In the app: ☰ → Settings → Artwork & metadata → paste into FanArt.tv key → Save (a ✓ shows it works)
Free

Discogs

Finds label names that iTunes and MusicBrainz miss, and fetches label logos.

  1. Sign in (or register) at discogs.com
  2. Settings → Developers → Generate new token
  3. Copy the token
  4. In the app: ☰ → Settings → Artwork & metadata → paste into Discogs token → Save (a ✓ shows it works)

Environment variables

Everything the container understands — the configurator above sets the ones you need.

VariableDefaultPurpose
PORT3399HTTP port for this app
ROON_CORE_IP(discover)Roon Core address for setups where multicast discovery can't reach it (macOS / Docker Desktop)
ROON_CORE_PORT9330Roon Core API port used with ROON_CORE_IP — only change it if your Core runs its API on a non-standard port
MUSIC_DIR/musicWhere the optional read-only music mount lives inside the container — the scan reads everything under it, so several folders can be mounted as subdirectories. Used for file-tag labels, release dates, local waveforms, the local-files badge and the format filters
TZEtc/UTCThe container's local time. Sets when Album of the day turns over (00:01) and the hour Smart Picks and Discover run. The 6- and 12-month "not played" windows are counted in absolute time and are unaffected
RRA_DISCOGS_KEY(unset)Seeds the Discogs token on a fresh data volume, so label logos work from the first scan. A token saved in Settings wins over it, and an env-seeded one is not written to disk — unset the variable and the key is gone
RRA_FANART_KEY(unset)Seeds the FanArt.tv key the same way
RRA_DEBUGon in DockerVerbose logging (timestamps, Roon API call traces with durations). On by default inside Docker — 0 for quiet logs

First run

The container is up — four steps and you're listening.

  1. Enable the extension in Roon. Roon → Settings → Extensions — Rouen (publisher MusicD) appears there once the container is running. Click Enable.
  2. Open the app. Browse to http://<your-server-ip>:3399 from any phone, tablet or desktop on your network. Add it to your home screen for an app-like experience.
  3. Add your API keys. ☰ → Settings → Artwork & metadata → paste in the keys from above. For labels, switch on Settings → Labels → Record labels and let the label scan run.
  4. Optional: wall display. Switch on Settings → Wall display, then point a TV or spare tablet at http://<your-server-ip>:3399/display.
