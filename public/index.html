MusicD Remote
Switch to Docker — Updates are now Docker-only. Download the latest release from github.com/meltface-80/MusicD-Remote/releases/latest, then run (replacing VERSION with the release you downloaded): 
sudo mkdir -p /opt/musicd-remote && cd /opt/musicd-remote
wget https://github.com/meltface-80/MusicD-Remote/releases/download/vVERSION/MusicD-Remote-vVERSION.tar.gz
tar -xzf MusicD-Remote-vVERSION.tar.gz
docker build -t musicd-remote:VERSION .
docker run -d --name musicd-remote --restart unless-stopped --network host -v musicd-remote-data:/app/data musicd-remote:VERSION
sudo systemctl stop musicd-remote && sudo systemctl disable musicd-remote
